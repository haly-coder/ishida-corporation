# 石田自動車 LP（ISHIDA CORPORATION）

タイヤ交換・パーツ取付・レッカー対応・新車/中古車販売・自動車保険まで手がける車屋のランディングページです。
[S5-Studios](https://www.s5-studios.com/) のダークネイビー×クリーム、太いセリフ見出し、有機的な装飾、スクロール演出といったデザイン言語を参考に、若年層に向けたスタイリッシュなトーンで制作しています。

## 構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル
- `assets/script.js` — ヘッダーのスクロール反応、スクロールインジケーター、フェードイン演出、モバイルメニュー
- `assets/images/car-coupe.jpg` — [Pexels](https://www.pexels.com/photo/white-sports-coupe-733745/) のフリー素材（Pexelsライセンス、商用利用可・クレジット表記不要、撮影者: Cesar Perez）

## ローカルで確認する

```
open index.html
```

## GitHub Pages で公開する

1. GitHub のリポジトリ画面で **Settings > Pages** を開く
2. **Source** を `Deploy from a branch` に設定
3. Branch を `main` / フォルダを `/ (root)` に設定して Save

## 編集が必要な箇所

`index.html` 内の以下はプレースホルダーです。実際の情報に差し替えてください。

- 会社概要セクションの所在地・設立・代表者・営業時間
- お問い合わせ／緊急連絡のメールアドレス・電話番号（`tel:0000000000` を含む）
- 年間対応実績などの数値
